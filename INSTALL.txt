HCQ 1.2.0 — Windows Installation
================================

Requirements
------------

- Windows 11
- Houdini 21.x
- No separate Python or PySide6 installation

Recommended installation
------------------------

1. Close Houdini, hython, and hbatch.
2. Download and run HCQ-Setup-1.2.0.exe.
3. Keep the default current-user installation.
4. Start Houdini 21.x.
5. Open the HCQ shelf and click HCQ, or create a Python Panel and choose
   "HCQ — Houdini Cook Queue".

Setup installs the program at:

  %LOCALAPPDATA%\Programs\HCQ

It registers the same program with every detected Houdini 21.x preference
folder, including the user-profile location used by hython. Administrator
access is not required.

Houdini Package Browser installation
------------------------------------

1. Download HCQ-1.2.0-houdini-package.zip.
2. Open Inspectors > Package Browser in Houdini.
3. Choose File > Install Package Archive.
4. Select the ZIP and an installation folder.
5. Accept the installation and open the HCQ shelf or Python Panel.

Upgrade from HCQ 1.1.x
----------------------

Windows Setup migrates the old copy-installed layout. Manifest-owned plug-in
files are backed up and removed, while settings, queues, run history, logs,
and recovery data remain under $HOUDINI_USER_PREF_DIR\HCQ.

HCQ-1.2.0-windows.zip is provided only as an updater bridge for existing
1.1.2 installations and as an advanced manual fallback.

Updates
-------

Click Update in the HCQ panel header. HCQ validates the latest stable GitHub
Release and SHA-256 checksum before staging files. Choose Restart Now to use
Houdini's standard save prompt and automatically reopen the current saved HIP,
or choose Later.

Uninstallation
--------------

Close Houdini and uninstall HCQ from Windows Installed Apps. Program files and
Setup-owned Package JSON registrations are removed. Choose No when asked about
user data to keep settings, queues, history, logs, and recovery.

HCQ does not install third-party Python packages.
